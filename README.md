# 生活好帮手 · 订阅刺客体检仪

面向支付宝「智能体涌现奖 2026」（生活好帮手赛道，作品编号 `6ebc96914f8eab`）开发的端侧智能订阅审计与消费决策助手，覆盖自动续费 **事前拦截（买前扫雷）→ 事中体检（账单扫描）→ 事后追回（自助申诉模板 + 人工二次确认解约）** 全生命周期。

## 在线体验（电脑与手机竖屏均可直接打开）

- 在线演示地址：`https://breakneo.github.io/earn-alipay-subguard/`

## 核心亮点

1. **端侧离线隐私保护**：账单 CSV 拖拽、扣费短信解析、美元汇率折算与三色止血处方全部在浏览器本地完成（0 字节上传云端）。
2. **双引擎智能架构**：默认采用端侧规则引擎确保金额精算零误差；支持在顶栏「大模型设置」中一键开启真实大模型语义增强（兼容通义千问、豆包大模型、DeepSeek 及自定义限流代理），网络异常时自动无感回退。
3. **人工二次确认安全锁**：涉及解约免密与提交退费申诉的操作强制由本人二次确认，绝不静默代操；维权模板明确标注仅供参考，不构成正式法律意见。
4. **配套阿宝技能规范**：仓库内提供完整技能说明与工具接口契约（`skills/alipay-subguard/SKILL.md`、`tools-schema.json`），便于未来直连支付宝「阿宝」开放能力。
