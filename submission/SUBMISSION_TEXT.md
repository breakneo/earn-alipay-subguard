## 1. 团队 / 个人介绍

我是一名长期关注日常效率工具与端侧 AI 智能体落地的独立全栈开发者（GitHub: `@breakneo`）。平时在工作和家庭生活中经常帮自己和父母排查手机里的莫名扣费，深感“隐形自动续费”是一个高频却缺乏趁手工具的国民痛点，因此独立设计并开发了这款面向支付宝「阿宝」生态的轻量化生活助手。

## 2. 创意名称 + 创意介绍

- **创意名称**：生活好帮手+订阅刺客体检仪（Alipay Abao × SubGuard Skill）
- **动机与灵感来源**：身边几乎每个人都有过类似经历——自己为了看一部剧或领一张券点了“首月 1 元”连续包月，半年后翻账单才发现被静默扣了几百元；家里长辈更常在看新闻或清理手机弹窗时误触免密支付，每月被扣 29.9 元却浑然不知；甚至开发者自己也会同时叠加多个昂贵的海外 AI 订阅。现有做法只能靠人工一条条翻账单、再挨个找客服扯皮，门槛极高。
- **一句话概括产品形态**：一款深度结合支付宝「阿宝」对话入口与端侧隐私离线计算的 **Web 智能体应用 + 标准 Agent Skill 技能包（`SKILL.md` + `tools-schema.json`）**，覆盖自动续费“事前防坑、事中体检、事后追回”全生命周期。

## 3. 目标用户及痛点

本作品主要服务三类支付宝高频用户：
1. **都市上班族**：在影音、网盘、外卖、阅读、修图等平台同时存在多项周期扣款，极易踩中“首月 1 元、次月 28 元”阶梯涨价、0.01 元试用转包年以及多平台同质化重复付费陷阱；
2. **银发长辈及帮父母管账的子女**：长辈易在弹窗广告中误开“清理大师 / 天气 VIP”等伪刚需免密扣款，子女不在身边时难以远程排查与解约；
3. **重度数字工具与 AI 订阅用户**：人民币与美元多币种订阅叠加，缺乏一眼看穿年度隐形漏财和 3 年复利流失的体检仪表盘。

**产品具体帮助用户完成什么**：把原本需要 1–2 小时人工翻账单、查关闭入口、写投诉理由的繁琐流程，压缩成在「阿宝」里的一句话唤起与 30 秒一键止血闭环，真正帮用户“看清漏财、挡住诱饵、关掉免密、追回误扣”。

## 4. 功能介绍与实际价值

### 一、阿宝对话工作台（一句话调度订阅保镖 Skill）
用户在「阿宝」对话舱内直接输入口语需求（如“拉取近 90 天账单查刺客”“帮我扫雷首月 1 元次月 28 元会员”“帮爸妈查误触免密”“追回昨晚静默扣款”），系统实时路由至对应 Skill 工具链，并透明展示每一步工具调用轨迹。所有账单解析默认在端侧本地完成（0 字节上传云端），最大限度守护财务隐私。

### 二、事中体检：阿宝账单授权同步 + 本地离线 CSV/短信解析
- **4 种零门槛导入**：支持模拟「阿宝一键只读授权同步近 90 天周期账单」（内置打工人、银发长辈、AI 开发者 3 套真实脱敏账单 1 秒体验）、直接拖拽本地支付宝/微信导出 CSV 账单（自动兼容 UTF-8 / GBK）、粘贴任意扣费短信（自动识别人民币与美元并折算汇率），以及 30+ 国民高频订阅一键勾选自查。
- **红 / 黄 / 绿三色止血处方**：自动识别首月低价暴涨刺客、同品类重复订阅、近 30 天零使用沉睡扣费与长辈误触高危项，量化年度总支出、预计可立省金额与 3 年累计止损，并保留真正高频刚需项不误伤。

### 三、事前拦截：浏览订阅页唤起阿宝实时扫雷
在用户准备点击“同意开通免密”前，唤起阿宝粘贴活动条款或输入首期价/续费价，3 秒拆穿隐形涨价倍率（如 28 倍涨价）与首年真实总成本，同时自动碰撞用户当前在途账单预警功能重叠，给出“强烈劝退 / 改买单次卡 / 可控开通并设次期到期前 48 小时阿宝强提醒”的买前裁决。

### 四、事后追回：阿宝 + 订阅保镖 Skill 自动申诉闭环（强制二次确认）
针对已发生的误扣或静默自动续费，系统自动评估 7 日窗口期、零权益消耗与《网络交易监督管理办法》第十八条（自动续费前五日显著提醒义务）计算追回胜率，一键生成可直接复制的**支付宝账单投诉举证单**与**商户在线客服退费话术**，并附支付宝、微信、Apple iOS 全渠道精确关闭免密步骤与《家庭订阅止血体检单》一键导出。在涉及账户状态变更的“解除免密协议”与“提交退费申诉”环节，严格落实 **Human-in-the-Loop（人工二次确认）安全红线**，绝不静默代操。

### 五、作品特色与接入「阿宝」的持续经营价值
本作品不是套壳闲聊机器人，而是用确定性规则引擎 + 端侧离线解析 + 标准 Agent Skill 契约构建的真实生活基础设施。当前 Web 版通过脱敏沙盒与纯本地解析确保评委开箱即用，仓库已同步交付完整的 `skills/alipay-subguard/SKILL.md` 与 `tools-schema.json`；未来接入支付宝「阿宝」开放能力后，可直接串联支付宝账单、免密支付管理与订单申诉服务，成为国民级“家庭财务防坑守门员”。
